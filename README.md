# Todo List App (Next.js + MongoDB)

A full-stack Todo List application built with **Next.js**, **TypeScript**, 
and **MongoDB**. Users can add, delete, complete, and undo completed tasks. 
Completed tasks are displayed on a separate page using Next.js routing, 
and task data is persisted in a MongoDB database.

## Features
- Add new tasks
- Delete tasks
- Mark tasks as complete
- Undo completed tasks
- View completed tasks on a separate page
- Persistent storage using MongoDB

## Tech Stack
- Next.js
- TypeScript
- React
- MongoDB

## Getting Started

1. Clone the repository
```bash
git clone <your-repo-url>
```

2. Install dependencies
```bash
npm install
```
